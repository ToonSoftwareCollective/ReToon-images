# ReToon documentation

How to use ReToon once it is on your Toon. Installing it is done with the
[ReToon setup app](https://github.com/ToonSoftwareCollective/ReToon); the
apps are in [ReToon-apps](https://github.com/ToonSoftwareCollective/ReToon-apps).

- [The web interface](web-interface.md): logging in, pages and cards, all settings
- [The screen](screen.md): using it, the cards, the dashboard format, the Home Assistant link
- [The thermostat](thermostat.md): presets, week program, starting early, sensors
- [MQTT](mqtt.md): the Toon's own broker, the Toon in Home Assistant, notifications
- [Apps](apps.md): installing, settings, updating
- [Z-Wave](zwave.md): the Toon's Z-Wave controller with Z-Wave JS
- [Bluetooth proxy](bluetooth.md): Bluetooth devices near the Toon in Home Assistant (Toon 2)
- [Zigbee and Thread](radio.md): the Toon 2's radio for zigbee2mqtt or as a Thread border router
- [Sound](sound.md): sounds, tones and the volume
- [Status](status.md): what works, what is not tested yet, what is not done

What changed in each version is in the notes of each
[release](https://github.com/ToonSoftwareCollective/ReToon-images/releases).
